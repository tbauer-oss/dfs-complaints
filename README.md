# dfs-complaints

## DeepL translation setup

The admin-side automatic FAQ translations require a valid **DeepL API** authentication key (from a DeepL API subscription). Keys that are issued for CAT-Tool plugins are not accepted by the DeepL API endpoints we call. Provide the API key via `DEEPL_API_KEY` (or `DEEPL_AUTH_KEY`/`DEEPL_KEY`) and, if necessary, a custom endpoint via `DEEPL_API_URL`.
